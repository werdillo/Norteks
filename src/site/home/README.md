# home

The landing page's own content: the hero slider, the introduction with its figures, «О компании» with the
range of fabrics, and the call to action above the footer. Static; the copy is in `data.ts`. The page passes
`types` (the catalog's fabric types: counted, and the fabric names link to them) and `phone`. Two named slots let the home page fill the advantages and the
catalog: `advantages` and `catalog`.

Door (`index.ts`): `HomePage`.
